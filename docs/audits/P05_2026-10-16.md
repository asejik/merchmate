# P05: Architecture and Product Quality Review, 2026-10-16

**Scope:** MerchMate Phase 1 at `47f3eed`, fixes in `637e613`.
**Not available:** `docs/AUDIT_STANDARD.md`, `docs/PROJECT_PLAN.md` and `docs/DESIGN.md` do not exist. I judged feature completeness against `README.md` and `CLAUDE.md`, and defined the core user journeys myself (below). This is a solo, non-client project, so there is no requirements traceability table or client acceptance statement.
**Method:** code review (file sizes, patterns, types), a scripted walkthrough of the real app at **360px** (Chromium, touch) with **axe-core** (WCAG 2.2 AA rules) run on 15 screen states, an automated touch-target scan, keyboard/dialog/reduced-motion checks, a desktop (1280px) layout check, and the unit test suite.

**Core journeys used**
1. First minute: open an empty app, set up the business, add a client
2. Create an invoice and see it listed
3. Get paid: record a payment, get a receipt, balance updates
4. Chase: WhatsApp reminder, order stages
5. Quotes: create and convert to an invoice
6. Protect your data: backup, restore, App Lock, erase

Journeys 1 to 4 were walked step by step in this audit; 5 and 6 were exercised in earlier audits and unit tests (P03/P04, quotes and conversion are covered by `quotes-catalog.test.ts` and `mutations.test.ts`).
